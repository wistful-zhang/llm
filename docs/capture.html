两种去向

保存后只需选择一次去向

  1. 只留给自己点保存后立即回到“我的题目”，可以编辑、搜索、练习和导出。
  2. 题库主人正式收录把题目卡中的指令交给 Codex，所选分类和难度会一并保留；也可在 Pages CMS 手工录入。通过检查和发布后才进入正式搜索、分类和模拟面试。
  3. 其他人公开补充使用题目卡中的“提交公开补充”进入 GitHub 最终确认；分类和难度已自动带入，不需要再选。打开确认页时题目内容会发送给 GitHub，点击提交后才创建公开 Issue。
