# 隐私说明

网站没有本站账号或行为统计。题库阅读不要求登录；选择“私人”的题目、面试记录和模拟练习进度保存在浏览器本地，不会上传。私人题仍会显示在统一题库列表中，但会标注“私人”，其他访客看不到。只有主动选择“公开”并保存题目时，网页才会把该题发送到题库主人配置的共享题目服务；题目评论当前关闭。

## 浏览器里保存什么

- **我的题目**：题目、答案草稿、分类、难度、标签、匿名来源和“公开 / 私人”选择，保存在 `localStorage`。私人题只在当前浏览器显示；公开题点击保存后会同时写入共享题库。
- **公开题修改凭据**：公开发布时浏览器会生成随机修改凭据。服务端只保存其不可逆摘要，原始凭据仅留在当前浏览器，用于以后修改或撤回自己的公开题。清除浏览器数据后无法恢复这份作者权限。
- **面试记录**：公司匿名代号、岗位、轮次、结果、下一步和复盘，保存在 `localStorage`。
- **模拟练习**：未完成场次和最近一次复盘结果，保存在 `localStorage`。
- **旧评论修改凭据**：如果这个题库过去启用过评论，浏览器中可能仍有昵称和随机修改凭据；当前关闭评论后不会再创建新的凭据，清理站点数据即可删除旧数据。
- **保存多久**：浏览器会一直保留，直到你主动清除、浏览器清理站点数据，或存储空间发生变化。
- **怎样删除**：“＋题目”的“删除全部本机题目”和面试记录页的“彻底删除本机记录”会删除各自数据；浏览器设置也可以删除整个站点的数据。

“仅当前浏览器”不是账号鉴权或加密。同一浏览器资料中的其他使用者可能看到记录；同一个 `username.github.io` 域名下的其他项目也共享浏览器 Origin，理论上可以读取相同 Origin 的本地存储。请使用公司匿名代号，不要保存姓名、联系方式、会议链接、精确薪资、公司机密或受 NDA 约束的信息。更高隔离要求应使用独立域名、独立浏览器资料或专门的加密记录工具。

## 备份文件

导出的 JSON、CSV 和 Markdown 是未加密明文文件。JSON 用于恢复题目或面试记录内容，CSV 用于表格查看，Markdown 用于把单题提交到仓库；下载后由你负责存放、传输和删除。题目 JSON 不包含公开题修改凭据，所以换设备后可以恢复内容，但不能接管原设备发布的公开题。换设备、仓库改名、转移 Owner 或切换网站地址前，请分别导出本机题目和面试记录 JSON，再到目标站点恢复。

## 页面会请求哪些外部服务

- 题目公式按需从 jsDelivr 加载 MathJax 文件和字体。
- 创建题库按钮会请求 GitHub 的公开仓库 API，用于判断应复制当前模板还是基础模板；请求不包含本站面试记录。
- “配置自检”会请求 GitHub 的公开仓库与 Actions API，读取仓库可见性、默认分支、Pages 状态和公开工作流运行结果；无需也不会收集 Token，不会读取本站面试记录。
- 首页会从题库主人配置的共享题目服务读取已经公开的题目。选择“私人”不会请求该服务；选择“公开”并保存时，会发送题目、答案、追问、分类、难度、标签、匿名来源、随机请求标识和人机验证结果，成功后立即对所有访客可见。
- 共享服务使用按日不可逆限流值防刷，不把原始 IP 或 User-Agent 写入题目数据库；Cloudflare 平台仍可能按自己的规则保留必要的网络日志。
- 当前关闭题目评论，因此题目页不会发送或读取评论。若题库主人以后主动恢复评论，评论数据才会写入其单独配置的服务功能。
- 点击“GitHub 仓库”或 Pages CMS 后会离开本站，这些操作受对应服务的隐私政策约束。公开仓库里的题目文件、Pull Request 和附件没有单条私密开关，提交前必须脱敏。

本站自身没有配置广告、统计脚本或站内账号 Cookie。Cloudflare、GitHub Pages、浏览器和你主动打开的外部服务仍可能按各自规则处理必要的网络日志。

## 公开题共享服务

公开题一经保存就会直接显示，不存在发布前审核队列。发布者可在保留原始修改凭据的浏览器中编辑或撤回；题库主人只在发现隐私、NDA、侵权、广告或其他滥用时事后下架。公开前请自行确认有权分享，且内容已经脱敏。

每个从模板创建的题库都应部署和配置自己的共享题目服务，不会继承原题库的数据地址。未配置共享服务时仍可使用私人题、仓库内置题、搜索和模拟面试，但网页不能把“公开”冒充为已发布。

## 若以后恢复公开评论

- **长期公开内容**：昵称、评论正文、楼层、回复关系、发表和修改时间会保存在题库主人的 D1 数据库，直到评论者在原浏览器删除或管理员处理。评论没有“仅自己可见”选项。
- **防刷信息**：评论服务不会把原始 IP 或 User-Agent 写入评论数据库；它只保存由轮换密钥生成的按日不可逆限流值，并结合 Turnstile 判断是否为正常请求。Cloudflare 平台仍可能按自己的规则保留网络日志。
- **举报与管理**：举报只记录目标评论、固定原因、时间和按日限流值。举报不会自动隐藏评论，管理员核对后可以隐藏、恢复或删除。
- **内容许可**：评论者保留自己文字的权利，同时授权题库运营者为了展示、排版、备份、审核和删除而处理该评论。普通评论不会自动成为项目 MIT 代码贡献。

每个使用者从模板创建的新题库默认关闭评论，也不会继承原作者的数据库地址。只有题库主人以后主动部署自己的服务、设置 GitHub Actions 公开变量并打开评论后，网页才会连接对应服务。Private / Internal 题库不应启用公共匿名评论。

## Pages CMS 与 GitHub

Pages CMS 是可选的第三方编辑界面。授权后，它可以读取和修改你选中的仓库，并可能缓存仓库配置、内容和权限信息；Private 仓库内容也会经过获授权的服务。建议只授权题库仓库，并定期在 GitHub 的 **Settings → Applications → Installed GitHub Apps** 中复查或撤销权限。不使用 Pages CMS 时，可以直接在 GitHub 网页编辑器中维护文件。

任何进入 Public 仓库、Issue、Pull Request 或 GitHub Pages 的内容都应视为公开。网页上的“未发布”开关不能隐藏 Public 仓库中的源文件或 Git 历史。
