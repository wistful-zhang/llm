# 关于这份笔记

这是一个可复用的大模型面试准备与复盘网站。你可以浏览题库、随机模拟、直接在网站 UI 中增加题目、在浏览器记录真实面试进度，也可以使用同一套项目建立属于自己的公开或私有题库。

## 整理原则

- **直接回答问题**：开头就回应题目，不用先介绍自己准备怎么答。
- **按题型展开**：原理题讲因果，设计题讲约束，项目题讲真实证据。
- **只说真实经历**：没有做过的项目可以讲推演，但不要编造指标和事故。
- **准备追问**：把面试官可能继续深挖的方向列出来。
- **练习口述**：60 秒是上限，不是必须填满；说清楚后就收尾，再对照参考说法复盘。

## 来源与核验

内置基础题库只保留 232 道“资料核验”题，每道都附有用于核对技术事实的参考资料。此前 768 道批量扩展题只有类别级通用“延伸阅读”，没有逐题核对答案与资料，已从主题库移出并固定归档，不参与搜索和模拟面试。

带“资料核验”标记的题目已经检查答案的技术依据、七段答题结构、追问接法和参考链接，具体依据列在每道题末尾。这个标记表示技术内容有可追溯资料，不等于证明它来自某家公司真实面试；是否有明确面经来源，应以该题列出的链接为准。不同团队也未必采用完全相同的标准答案，面试时仍应结合岗位和项目经验说明取舍。

当前 {{ published_question_count }} 道公开题中，{{ verified_question_count }} 道标记为“资料核验”；以后新增的题目会按自身答案和资料状态单独显示。题目数量和核验状态都不表示每道题同等重要或都应默认学习。本站用“核心必会 / 岗位专项”标记当前备考顺序，并保留“扩展知识点 / 待重整”供新增个人题目使用；它与题目难度、是否公开和个人复习状态相互独立。具体含义和不同岗位的学习路径见[学习分级说明]({{ '/study-tiers/' | relative_url }})。

## 如何使用

第一次准备时，先按[学习分级]({{ '/study-tiers/' | relative_url }})筛选“核心必会”，再进入[模拟面试]({{ '/practice/' | relative_url }})按目标岗位和分类抽题：先口头回答，再查看参考答案并标记掌握程度；也可以浏览单题，点击“开始口述”，之后用“面试时怎么答”和“常见追问”检查表达与知识盲点。

临时想到问题时，可以打开[增加题目]({{ '/capture/' | relative_url }})，填好一次分类、难度和可选答案，然后只选择“私人”或“公开”。两种题都显示在同一个题库列表中：私人题会标注“私人”，只保存在当前浏览器；公开题点击保存后直接写入共享题库，不需要 GitHub、Issue 或人工审核。两者都允许只写问题，答案和追问以后再补。

本站当前关闭题目评论，优先把增加题目、补答案、模拟练习和面试复盘做好。公开题发布成功后立即进入题库；作者可在原浏览器修改或撤回，站主只在发布后处理涉及隐私、NDA、侵权和明显滥用的内容。“资料核验”只说明答案是否已核对参考资料，不是发布门槛。

真实面试后，可以打开[面试记录]({{ '/interviews/' | relative_url }})保存公司匿名代号、岗位、轮次、结果、下一步和个人复盘。记录默认只在当前浏览器中可见，不会写入 GitHub；换设备前需要导出 JSON 备份。每个流程都可以保持“仅当前浏览器”，也可以标记为“准备匿名分享”；后者仍然不会自动上传，必须先生成匿名预览，再通过[公开面经发布步骤]({{ '/experiences/manage/' | relative_url }})二次确认。已经明确公开的内容会显示在[公开面经]({{ '/experiences/' | relative_url }})。

如果想建立自己的题库，请查看[使用指南]({{ '/start/' | relative_url }})。整个项目不依赖固定用户名或仓库名。

本站如何使用浏览器存储和外部服务，见[隐私说明]({{ '/privacy/' | relative_url }})。
